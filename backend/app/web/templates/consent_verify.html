Permission for {{ child_name }}

Anointed is a Bible character quiz game. Because {{ child_name }} is under 13, we need a parent or guardian's permission before the account can be used.

Draft disclosure. This page uses COPPA-oriented language pending legal counsel review. Do not rely on it for a production launch without sign-off.

What we collect

  • {{ child_name }}'s first name and age (age is used only to decide which rules apply)
  • A mobile number, if one was entered when signing up
  • Game progress: which levels were played, scores, and answer timings
  • Basic app usage events so we can see which levels are too hard
  • Your name, email, and relationship to {{ child_name }} — kept as the record of this permission

What we do not do

  • No advertising is shown to players under 13
  • No advertising identifiers or cross-app tracking for players under 13
  • The leaderboard shows only a first name and last initial for players under 13

You can ask us to delete {{ child_name }}'s data at any time from inside the app (Profile → Delete my account), or by contacting {{ support_email }}. Full details are in our Privacy Policy (version {{ policy_version }}).
